  完整实验工作量 / (单次时限 - 每次启动与恢复 - 退出余量)
) + 抢占/故障造成的额外尝试

196.206h 尚不是式中的完整实验工作量；不得重复计算已计入的固定 10% 附加量，也不能

实际阶段成本与抢占原因后再调整显式部署配置，保留历史 attempt 记录。

### 11.4 已实现：有界重入、启动预算和一致预警

学校包装已在断点检查/环境加载前登记尝试和预算，因硬杀来不及结算的记录会在重入时按
顺序核对。检查阶段尚未启动训练的尝试计为无进展，训练阶段依据持锁读取的实际 checkpoint
判断；矩阵识别固定的未完成子 run，支持遗留 running/failed 状态和尚无初始 checkpoint。
完成阶段数、epoch、提交游标及成功更新参与比较；仅阶段名改变不计推进，倒退明确失败。
旧计数文件保留原 attempts/累计预算，不通过迁移清零。

可观测初始化/训练失败统一记录错误阶段并结算实际耗时；硬杀保守保留预记预算。达到连续
无进展上限后，核对用的 allocation 以 blocked 记录退出，不启动训练。结果和计数提交、
scratch 清理全部完成后才请求 requeue，避免新一轮先启动而旧记录尚未落盘。

提交器由 runtime 余量生成预警提前量；作业验证导出的提前量与实际 runtime 一致。
`srun` step 在依赖和配置载入后重新查询剩余时长，并保留启动前已确定的较短截止时间。
适配器建立通用控制器后调用原单模型或矩阵实现，通用层仍不读取 Slurm。实际预算、启动
开销和每次结算文件详见 [ICF 操作说明](../../configs/deployment/icf/README.md)。

本地真实子进程 SIGKILL + fake Slurm 已覆盖连续两次在检查/初始化期间被杀、无初始断点、

不替代学校 Slurm、GPU、Lustre 和跨节点验收。
