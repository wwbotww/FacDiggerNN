# 因子效果诊断与实验改进方案：当前研究概览

**科学结论依据10月15日完整F/S汇总，于2026-10-18复核；优先级同步本轮结果。** V/holdout关闭。
本页只维护当前判断、证据缺口和优先级。设计、结果与当时决策在实验记录，精确参数和
逐次运行状态在冻结配置、机器产物及收据；通用协议见[实验设计文档](实验设计文档.md)。

## 当前最重要的结论

1. **模型能学习，但复杂模型的增益依赖时期。** 旧60与新45个cell的最终F拟合均较
   第1轮改善；Finance原LR在wf2/wf3各5/5 seed低于Linear，小LR在wf3仍各5/5落后。
   这是开发证据，尚未证明充分拟合、稳定外样本增益或可发布因子。
   [参照结果](实验记录/2026-10-08_完整F-S参照实验.md#complete-reference-results)与
   [干预结果](实验记录/2026-10-13_市场条件Linear与小学习率对照.md#intervention-results)
2. **延长训练不是统一答案。** 原LR Finance在wf1的best落在6–10轮，wf2在1–3轮；
   非线性模型在部分时期完整F改善而S退化。当前原生S-best已保留，末轮退化不等于
   best被覆盖。需区分优化路径、泛化和时期依赖，不能统一缩成两轮或直接加epoch。
3. **状态交互和小LR都有局部增益，尚非通用修复。** 条件Linear在wf1的选择分数和
   S IC均5/5改善，但wf3平均IC下降，选择分数提高来自较小的分段波动惩罚。
   两种小LR模型在wf2改善、wf1较弱；MLP部分晚期S改善伴随F明显落后，Finance
   wf3的F/S分歧仍在。先前dropout也未获得一致收益，不据此继续盲目扩大正则/LR网格。
   [45-cell配对结果与局限](实验记录/2026-10-13_市场条件Linear与小学习率对照.md#intervention-results)
4. **尚无干净SSL增益或“模型太旧”的因果证据。** 当前参照全为scratch，时间分段
   没有共同单调衰减；旧预训练有旧选择/计算池/预处理局限，不能替代新对照。
   full-Train refit保留为受控候选，不是预设主方案。
5. **工程完成与因子有效分开。** 完整监督训练和一次超过24小时的正常运行提供工程
   证据；真实硬杀/跨allocation/跨节点及完整SSL/probe故障恢复仍须单独验收。
   `source_research_ready=false`以及PIT行业、流通市值和退市资料限制仍在。
   新比较目录已封存105个原生S-best，但原包210监督/30 SSL条件未满足，V/holdout未评价。

F是拟合区间，S用于内层选择；V是开发验证，holdout另行隔离。早期R/C曾按当时约定
评价开发V，后续seed/dropout及60-cell只观察F/S。不能把已看过的V重新称作独立确认，
也不能把旧协议结果或诊断FP32重评分混作原生S-best的新协议结论。

## 未解决的问题与证据缺口

| 问题 | 已有证据能说什么 | 仍缺什么 |
|---|---|---|
| 是否充分拟合目标 | 完整F/loss改善；小LR拟合较慢，不证明更高上限 | 原定30轮流程对照；当前改善不等于收敛或最优 |
| 泛化为何退化 | 小LR和条件Linear未统一消除F/S分歧 | 辅助rank目标与股票间交互各自独立消融；风格投影仅为观察性解释 |
| 复杂度是否提供额外信息 | Finance未稳定胜出；条件Linear的改善也依赖时期 | 保存预测的增量/冗余诊断；原包其余结构对照与统一V比较 |
| 参数时效性是否关键 | 自然年份与模型年龄混杂 | 同长度旧静态、近期静态、季度滚动与单独full-Train refit对照 |
| SSL是否有帮助 | 旧loss/probe不足以证明干净增益 | A/P边界内random/SSL探针、配对微调、原两种SSL预算 |
| 工程长运行是否可靠 | 已有恢复测试、正常完整监督运行及单次24小时以上allocation | 独立完整生命周期、真实规模硬杀、跨allocation/跨节点恢复 |

## 最先推进的三项工作

10月18日以完整配对结果替代“先取得条件Linear与小LR结果”的待执行优先级；
原判断、新证据与替代理由保留在[原实验记录](实验记录/2026-10-13_市场条件Linear与小学习率对照.md#intervention-results)。
以下仍来自10月8日原包，各改变单独解释；是后续建议，本次检查未提交新训练。

| 顺序 | 工作与理由 | 依赖与边界 |
|---|---|---|
| 1 | 辅助rank项消融30个：检验1/20日辅助排序是否影响5日任务 | 保持三头、全期限L、5日系数.6及全部scale项；只去掉两个辅助rank梯度 |
| 2 | 股票间交互消融15个：检验复杂结构的增量是否值得保留 | 保留市场路径和配对初始化；只改变context中的其他股票信息，不与目标消融叠加 |
| 3 | 原定30轮对照、干净SSL及完整V执行器补齐 | 30轮按原LR从头开始；不追加“小LR×30轮”混合干预；原20项比较族及V门禁不变 |

时间更新与独立full-Train refit仍保留，工程长生命周期验收单列。依赖完整定义见
[扩展实验包](实验记录/2026-10-08_扩展实验包计划.md)；不把105个监督cell完成等同全部扩展工作完成。
