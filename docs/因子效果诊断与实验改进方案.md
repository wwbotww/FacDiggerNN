# 因子效果诊断与实验改进方案：当前研究概览

**科学结论截至2026-10-12；下一轮实施更新于2026-10-13。** 新批次仍只准许F/S；V/holdout关闭。
本页只维护当前判断、证据缺口和优先级。设计、结果与当时决策在实验记录，精确参数和
逐次运行状态在冻结配置、机器产物及收据；通用协议见[实验设计文档](实验设计文档.md)。

## 当前最重要的结论

1. **模型能学习，但复杂模型的增益依赖时期。** 完整60-cell参照中，最终F拟合均较
   第1轮改善；Finance在wf1的S有优势，在wf2/wf3却各有5/5 seed低于Linear。
   这是开发证据，尚未证明充分拟合、稳定外样本增益或可发布因子。
   [结果与指标口径](实验记录/2026-10-08_完整F-S参照实验.md#complete-reference-results)
2. **延长训练不是统一答案。** wf1 Finance的best落在6–10轮，wf2在1–3轮；
   非线性模型在部分时期完整F改善而S退化。当前原生S-best已保留，末轮退化不等于
   best被覆盖。需区分优化路径、泛化和时期依赖，不能统一缩成两轮或直接加epoch。
3. **dropout敏感性存在，但尚非通用修复。** 三seed两轮对照改善了固定epoch2的S，
   仍未消除F/S分歧；扩展到三时期五seed后，原生选择分数优势没有一致保持。
   [早期干预及局限](实验记录/2026-10-03_统计基线复现与Dropout对照.md#batch2-dropout-results)
4. **尚无干净SSL增益或“模型太旧”的因果证据。** 当前参照全为scratch，时间分段
   没有共同单调衰减；旧预训练有旧选择/计算池/预处理局限，不能替代新对照。
   full-Train refit保留为受控候选，不是预设主方案。
5. **工程完成与因子有效分开。** 60个监督cell全部完成、启动补跑成功；完整SSL/probe、
   24小时与跨节点故障恢复仍须单独验收。`source_research_ready=false`以及PIT行业、
   流通市值和退市资料限制仍在；本批V/holdout未评价，selection seal未创建。

F是拟合区间，S用于内层选择；V是开发验证，holdout另行隔离。早期R/C曾按当时约定
评价开发V，后续seed/dropout及60-cell只观察F/S。不能把已看过的V重新称作独立确认，
也不能把旧协议结果或诊断FP32重评分混作原生S-best的新协议结论。

## 未解决的问题与证据缺口

| 问题 | 已有证据能说什么 | 仍缺什么 |
|---|---|---|
| 是否充分拟合目标 | 完整F、固定目标loss和参数更新均改善；“完全学不动”优先级降低 | 预登记小LR/30轮流程对照；当前改善不等于收敛或最优 |
| 泛化为何退化 | F/S分歧、seed复现和时期差异已观察到 | 优化、目标、结构各自独立干预；风格投影仅为观察性解释 |
| 复杂度是否提供额外信息 | Finance未稳定超过匹配基线 | 市场条件Linear；保存预测的增量/冗余诊断；按原包冻结后的统一V比较 |
| 参数时效性是否关键 | 自然年份与模型年龄混杂 | 同长度旧静态、近期静态、季度滚动与单独full-Train refit对照 |
| SSL是否有帮助 | 旧loss/probe不足以证明干净增益 | A/P边界内random/SSL探针、配对微调、原两种SSL预算 |
| 工程长运行是否可靠 | 已有恢复测试与正常完整监督运行 | 独立完整生命周期、真实中断、跨allocation/跨节点及24小时验收 |
